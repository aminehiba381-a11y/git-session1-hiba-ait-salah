## Project description
This small HTML, CSS, and JavaScript website demonstrates a simple status message and basic project structure.

## Run the project
Open `index.html` in your browser, or run `python -m http.server 8000` in this directory.

## Files
- `index.html` — page content
- `style.css` — styles and layout
- `app.js` — dynamic status text
- `assets/project-banner.svg` — banner asset
- `Assignment1_Report.pdf` — report and local preparation record

## Git ignore rules
`local.env`, normal `.log` files and files under `tmp/` are ignored, except for `important.log`.
